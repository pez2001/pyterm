Optional sample overrides. Create sounds/<pack>/ (pack = chime, typewriter, 8bit, glass, cyber or your own name)
and put key.wav, key2.wav ... delete.wav, newline.wav, bell.wav, pick.wav, break.wav, gem.wav, boom.wav, boot.wav
(.wav/.ogg). Numbered variants are picked by character / at random. Everything else stays synthesized.
